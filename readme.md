# 🔥 Pelet Tracker Pro - PWA aplikacija

Kompletna offline PWA aplikacija za praćenje potrošnje peleta kroz grejne sezone.

## ✨ Karakteristike

✅ **Potpuno offline** - Radi bez interneta  
✅ **Instalira se na telefon** - Kao native aplikacija  
✅ **Automatski backup** - Nikad ne gubiš podatke  
✅ **Grafikoni i statistika** - Vizuelni prikaz potrošnje  
✅ **Temperature** - Automatsko preuzimanje sa Open-Meteo API  
✅ **Android ready** - Možeš build-ovati APK  

## 🚀 Brzi start
